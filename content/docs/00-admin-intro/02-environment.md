# 動作環境

pixi 管理画面はブラウザで利用します。専用アプリのインストールは不要です。

## 必須環境
| 項目 | 条件 |
|------|------|
| 端末 | PC（Windows / macOS） |
| ブラウザ | Google Chrome / Microsoft Edge / Safari の最新版 |
| ネットワーク | インターネットに接続できること |
| JavaScript | 有効であること |
| Cookie | 有効であること（ログイン状態の保持に使用します） |

## 推奨環境
| 項目 | 推奨 |
|------|------|
| ブラウザ | Google Chrome 最新版 |
| 画面解像度 | 横 1280px 以上 |
| 回線 | 有線または安定した Wi-Fi |

<Callout type="warning">
Internet Explorer には対応していません。画面が正しく表示されない場合は、まずブラウザを最新版に更新してください。
</Callout>

## スマートフォン・タブレットでの利用
管理画面は PC での利用を前提に設計されていますが、スマートフォンからもお使いいただけます。予約一覧・シフト・料金システムなどの主要な画面は、画面の幅に合わせた表示に切り替わります。画面の下には、よく使うメニューへのボタンが並びます。

<Callout type="tip">
外出先での確認や、急ぎの予約登録はスマートフォンでも行えます。ただしスケジュール（部屋ごとの時間割）やレポートのように横に広い画面は、PC のほうが見やすくなっています。
</Callout>
