# 本マニュアルの見かた

## 記事の構成
本書の各記事（節）は、次の 5 つの見出しで統一しています。目的に応じて必要なところだけ読めます。

| 見出し | 内容 |
|------|------|
| できること | その機能で何ができるかの一覧。まずここを読めば要否が判断できます |
| 事前準備 | 操作を始める前に必要な状態・権限・設定 |
| 手順 | 実際の操作。番号のとおりに進めれば完了します |
| 確認ポイント | 操作後に見ておくべきこと |
| よくあるミス | 実際に起きやすい間違いと、その回避方法 |

## 注記の種類
本文中には 4 種類の注記が登場します。枠の左端のラベルで見分けてください。

<Callout type="note" title="メモ">
補足情報です。知っておくと理解が深まりますが、読み飛ばしても操作は進められます。
</Callout>

<Callout type="tip" title="ヒント">
より効率よく操作するためのコツです。
</Callout>

<Callout type="warning" title="注意">
データの消失や誤った登録につながる可能性がある操作です。必ずお読みください。
</Callout>

<Callout type="step" title="手順">
複数の操作をまとめて示すときに使います。
</Callout>
