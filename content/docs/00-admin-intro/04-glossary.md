# 用語説明

本書で使う主な用語をまとめます。

## 権限・契約に関する用語
| 用語 | 説明 |
|------|------|
| オーナー | 店舗の責任者権限。店舗設定を含むすべての操作ができます。システム上は owner と admin の 2 種類がありますが、画面上はどちらも「オーナー」と表示されます |
| スタッフ | 日々の運用操作を行う権限。店舗設定にはアクセスできません |
| プラン | 契約内容。basic／pro／ultra の 3 種類があり、使えるメニューが変わります |
| 表示設定 | スタッフごとにメニューの表示・非表示を切り替える設定。レポート・経費・請求に適用されます |

## 予約に関する用語
| 用語 | 説明 |
|------|------|
| 予約 | お客様・キャスト・ルーム・コースを組み合わせた 1 件の受付 |
| Web予約 | お客様がご自身でWebから申し込む予約 |
| 予約フォーム内項目設定 | Web予約フォームに表示する入力項目の設定 |
| コース | 提供するサービスの単位。「お試しコース」と「通常コース」があります |
| オプション | コースに追加できる有料の選択肢 |
| 延長料金 | 規定時間を超えた分の料金。分数（例: 30）で設定します |
| 割引 | 料金から差し引く設定 |

## 指名に関する用語
指名料の名前は「料金システム」でお店ごとに登録します。決まった種類はありません。
よく使われる呼び方は次のとおりです。

| 用語 | 説明 |
|------|------|
| 本指名 | 以前に利用したキャストを名指しで指名すること |
| 写真指名 | 写真を見て、はじめてのキャストを指名すること |

## 人・場所に関する用語
| 用語 | 説明 |
|------|------|
| キャスト | 接客を担当するスタッフ。キャストアプリを利用します |
| 顧客 | 予約を申し込むお客様 |
| ルーム | 接客を行う部屋。ルーム名・表示名・エリアで管理します |
| スケジュール | キャストの当日の稼働予定 |
| シフト | キャストが申請し、店舗が確定させる勤務予定 |
| 募集枠（空きシフト） | 店舗が公開する、キャストが応募できる空きシフト |
| 予約不可（ブロック枠） | お客様の予約ではなく、その時間を埋めておくための枠。スケジュール画面だけに出ます |
| シフト申請外の対応 | キャストの確定シフトの時間からはみ出している予約に付く表示 |

## 経理に関する用語
| 用語 | 説明 |
|------|------|
| レポート | 売上などの集計。pro／ultra プランで利用できます |
| 売上 | お客様からいただいた金額 |
| 報酬 | キャストへの支払額 |
| 店落ち | 売上から報酬を引いた、店舗の取り分（売上 − 報酬 = 店落ち） |
| 経費 | キャストにかかった支出（交通費・衣装代など） |
| 請求 | **店舗が pixi にお支払いいただくご利用料金**。お客様への請求ではありません |
