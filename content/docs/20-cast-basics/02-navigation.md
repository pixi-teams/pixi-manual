# アプリの基本操作とナビゲーション

<Callout type="note" title="ご利用にあたって">
スマホ・PCどちらでも利用できます。スマホは画面下のメニュー、PCは画面左のサイドバーから移動します。どちらからでも同じ画面を開けます。
</Callout>

## できること
- 主要な画面（ホーム／予約／スケジュール／シフト／レポート）に移動できる
- 画面下のメニューに並べる項目を、自分でえらべる
- ヘッダーからマイページを開いたり、ログアウトしたりできる
- ヘッダーの通知ベルで通知を確認できる

## 事前準備
- ログイン済みであること

## 手順
### アプリにある画面
このアプリには次の8つの画面があります。

| 画面 | 内容 |
|------|------|
| ダッシュボード | 最初に開く画面。今日の予約とシフト |
| メッセージ | お店とのやりとり |
| 予約 | 予約の確認・登録・変更 |
| 顧客 | お客様の情報 |
| スケジュール | 自分の予定をカレンダーで |
| シフト | 出勤の申請・確認 |
| レポート | 自分の売上・稼働の集計 |
| 報酬 | 自分の報酬 |

### スマホでメニューを開く
スマホでは画面下部に5つのアイコンが並んでいます。押すとその画面に移動します。
はじめは次の5つです。

1. ダッシュボード（家のマーク）
2. 予約（フォルダのマーク）
3. スケジュール（カレンダーのマーク）
4. シフト（時計のマーク）
5. レポート（円グラフのマーク）

<Figure src="/manuals/cast/20-cast-basics/02-navigation/01-bottom-nav.jpg" alt="スマホ下部のメニュー。5つのアイコンが並んでいる" caption="画面下の5つのアイコンから各画面へ移動します" />

<Callout type="tip">
下のメニューに並ぶ5つは、**自分で入れ替えられます。**メニューの項目を長押しすると追加・解除ができ、並び順もドラッグ（押したまま動かす）で変えられます。顧客やメッセージをよく使う方は、入れ替えておくと便利です。
</Callout>

<Callout type="note">
下のメニューに出ていない画面（顧客・メッセージ・報酬など）は、画面左上の「☰」から開けます。
</Callout>

### PCでメニューを開く
PCでは画面左側にサイドバーが表示され、8つの項目がすべて並びます。
上の「お気に入り」の欄にはスマホの下メニューと同じ5つが入り、その下に残りが続きます。

<Figure src="/manuals/cast/20-cast-basics/02-navigation/02-pc-sidebar.jpg" alt="PC左側のサイドバー。お気に入りの5項目と、メッセージ・顧客・報酬" caption="PCではすべての項目が左側に並びます" />

<Callout type="tip">
項目の右にある星のマークを押すと、お気に入りに入れたり外したりできます。ここで変えた内容は、スマホの下メニューにもそのまま反映されます。
</Callout>

### マイページを開く・ログアウトする
1. 画面右上の、自分の名前が出ている部分を押します
2. メニューが開きます
3. 「マイページ」を押すと自分のページに移動します
4. 「ログアウト」を押すとログアウトできます

<Figure src="/manuals/cast/20-cast-basics/02-navigation/03-profile-menu.jpg" alt="右上のアバターを押して開いたメニュー" caption="名前の部分を押すとマイページ／ログアウトが表示されます" />

### 通知を見る
1. 画面右上のベルのアイコンを押します
2. 通知の一覧が表示されます。未読があるとベルに数字が付きます

<Figure src="/manuals/cast/20-cast-basics/02-navigation/04-notification-bell.jpg" alt="ベルを押して開いた通知一覧" caption="ベルのアイコンから通知一覧を開きます" />

## 確認ポイント
- 押したメニューの画面に切り替わること
- 右上の名前の部分からマイページ・ログアウトが開けること

## よくあるミス
- 下のメニューに無い画面（顧客など）が使えないと思ってしまう（左上の「☰」から開けます）
- ログアウトのつもりで名前を押しただけで閉じてしまう（メニュー内の「ログアウト」を押します）
