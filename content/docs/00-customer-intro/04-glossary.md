# 用語説明

本書で使う主な用語をご説明します。

## ご予約に関する用語
| 用語 | 説明 |
|------|------|
| Web予約 | Webページからお申し込みいただくご予約 |
| コース | ご利用いただくサービスの単位。「お試しコース」と「通常コース」があります |
| オプション | コースに追加でお申し込みいただける選択肢 |
| 延長 | 規定のお時間を超えてご利用いただくこと |
| 割引 | 料金から差し引かれる設定 |

## ご指名に関する用語
| 用語 | 説明 |
|------|------|
| 本指名 | 以前にご利用いただいたキャストを名指しでご指名いただくこと |
| 写真指名 | 写真をご覧になって、はじめてのキャストをご指名いただくこと |

ご指名の呼び方は店舗ごとに異なります。実際にお選びいただける種類は、ご予約の画面でご確認ください。
