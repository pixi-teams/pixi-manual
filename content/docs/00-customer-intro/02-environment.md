# ご利用環境

Web予約はブラウザからご利用いただけます。アプリのインストールは不要です。

## ご利用いただける環境
| 項目 | 条件 |
|------|------|
| 端末 | スマートフォン（iPhone / Android）・タブレット・PC |
| ブラウザ | Safari / Google Chrome / Microsoft Edge の最新版 |
| ネットワーク | インターネットに接続できること |
| JavaScript | 有効であること |
| Cookie | 有効であること（入力内容の保持に使用します） |

## 推奨環境
| 項目 | 推奨 |
|------|------|
| ブラウザ | iPhone は Safari、Android は Google Chrome |
| 回線 | 安定した通信環境 |

<Callout type="warning">
Internet Explorer には対応しておりません。画面が正しく表示されない場合は、ブラウザを最新版に更新のうえ再度お試しください。
</Callout>

## お申し込み時のご注意
- 通信が不安定な場所では、送信の途中で中断されることがあります
- 入力の途中でブラウザを閉じると、入力内容が失われる場合があります
- ご予約の確認メールを受け取るため、迷惑メールの設定をご確認ください
