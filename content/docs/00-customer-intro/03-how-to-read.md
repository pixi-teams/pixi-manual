# 本マニュアルの見かた

## 記事の構成
本書の各記事（節）は、次の見出しで構成しています。お急ぎの場合は「手順」だけお読みいただければお申し込みいただけます。

| 見出し | 内容 |
|------|------|
| できること | その画面でできることの一覧 |
| ご利用の前に | お申し込みの前にご確認いただきたいこと |
| 手順 | 実際の操作。番号のとおりに進めてください |
| 確認ポイント | 送信前にご確認いただきたいこと |
| よくあるミス | 起きやすい間違いと、その回避方法 |

## 注記の種類
本文中には 4 種類の注記が登場します。枠の左端のラベルでお見分けください。

<Callout type="note" title="メモ">
補足情報です。読み飛ばしてもお申し込みは進められます。
</Callout>

<Callout type="tip" title="ヒント">
よりスムーズにお申し込みいただくためのコツです。
</Callout>

<Callout type="warning" title="注意">
お申し込み内容に影響する重要なご案内です。必ずお読みください。
</Callout>

<Callout type="step" title="手順">
複数の操作をまとめてお示しするときに使います。
</Callout>
