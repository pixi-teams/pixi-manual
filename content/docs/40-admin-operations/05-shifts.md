# シフト管理

<Callout type="note" title="必要なプラン・権限">
pro／ultra のご契約でご利用いただけます。basic では「シフト」のメニューが表示されません。
</Callout>

## できること
- 月のカレンダーで、日ごとの出勤人数を確認できる
- その日に出勤するキャストの時間と部屋を確認できる
- 週ごと・日ごとの表に切り替えて見られる
- シフトを追加できる
- キャストが書いたメモを確認できる

## 事前準備
- 管理画面にログインしていること
- pro／ultra のご契約であること

## 手順

### シフトを開く
1. 画面左のメニューから「シフト」を押します
2. 月のカレンダーが開きます
3. 右側に「今日のシフト」が並びます

<Figure src="/manuals/admin/40-admin-operations/05-shifts/01-shifts.jpg" alt="シフト画面。左に月のカレンダー、右に今日のシフト一覧" caption="カレンダーの日付の下に出勤人数、右側に今日出勤するキャストが並びます" />

### 出勤人数を確認する
カレンダーの日付の下に「15名出勤」のように人数が出ます。人数が入っていない日は、まだシフトが登録されていません。

<Callout type="note">
オレンジ色で「20:00〜2:00」のように時間が出ている日があります。これは、その日にお店が募集している時間帯です。
</Callout>

### 今日出勤するキャストを見る
右側の「今日のシフト」に、キャスト1人ずつのカードが並びます。

| 表示 | 意味 |
|------|------|
| 名前 | 出勤するキャスト |
| 時間（例: 09:00 〜 12:00） | 出勤する時間 |
| Room ○ | 使う部屋 |
| 確定 | シフトが確定している |
| スタッフメモ | キャストや担当者が書いた申し送り |

<Callout type="tip">
黄色い枠の「スタッフメモ」は見落としやすい場所です。出勤前に必ず目を通してください。
</Callout>

### 表示のしかたを変える
画面の上に3つの切り替えがあります。

| 切り替え | 見えるもの |
|------|------|
| カレンダー | 月ぜんたいの出勤人数 |
| 週間シフト | 1週間分を、キャストごとの表で |
| 日シフト | 1日分を、部屋ごとの表で |

### シフトを追加する
1. 画面右上の「＋ 追加」を押します
2. 2つのうち、どちらかを選びます

| 選ぶもの | 何が登録されるか |
|------|------|
| シフトを追加 | キャストを指定して、その人の出勤を登録します |
| 空きシフトを追加 | キャストを決めずに募集枠だけを作ります。キャストがアプリから応募してきます |

3. 日にち・時間（・キャスト）を指定して登録します

<Callout type="note">
カレンダーにオレンジ色で「20:00〜2:00」と出ているのが、この「空きシフト」（募集枠）です。応募が集まって満枠になると表示が消えます。
</Callout>

## 確認ポイント
- 出勤人数が、実際の予定と合っていること
- スタッフメモに申し送りが入っていないか

## よくあるミス
- basic のご契約でシフトのメニューを探してしまう（pro／ultra だけの機能です）
- 月をまたぐ日（月末・月初）を、前後の月のカレンダーで探してしまう
- スタッフメモを読まずに当日を迎えてしまう
