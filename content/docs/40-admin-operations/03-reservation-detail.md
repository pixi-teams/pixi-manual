# 予約の詳細・変更

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご利用いただけます。
</Callout>

## できること
- 1件の予約の内容をまとめて確認できる
- お客様情報・予約内容・支払い情報を、それぞれ別々に変更できる
- 予約の状態（確定・キャンセルなど）を変えられる

## 事前準備
- 管理画面にログインしていること

## 手順

### 予約の詳細を開く
1. 画面左のメニューから「予約」を押します
2. 「本日の予約」のカードを押すか、下の「予約一覧」の右端にある「↗」を押します
3. その予約の詳しい画面が開きます

<Figure src="/manuals/admin/40-admin-operations/03-reservation-detail/01-detail-top.jpg" alt="予約詳細の画面。お客様情報・予約内容・支払い情報の3つのまとまり" caption="3つのまとまりに分かれていて、それぞれ別々に変更できます" />

画面は3つのまとまりに分かれています。

| まとまり | 内容 |
|------|------|
| お客様情報 | お名前・フリガナ・電話番号・メールアドレス |
| 予約内容 | 日時・コース・指名・オプション・状態など |
| 支払い情報 | 支払い方法と料金の内訳、合計金額 |
| SMS | お客様へのご案内SMSを送る（支払い情報のすぐ下） |

### 内容を変える
変えたいまとまりの右上にある「編集する」を押します。**まとまりごとに別々**なので、直したい部分だけを開けます。

1. 「編集する」を押します
2. 内容を直します
3. 保存します

<Callout type="tip">
たとえば電話番号だけを直したいときは、「お客様情報」の「編集する」だけを押します。予約内容や支払い情報は触らなくて済みます。
</Callout>

### 予約内容の項目
「予約内容」には次の項目が並びます。

<Figure src="/manuals/admin/40-admin-operations/03-reservation-detail/02-detail-bottom.jpg" alt="予約内容の下部。予約方法・登録スタッフ・ご要望" caption="下のほうに、予約方法・登録スタッフ・ご要望が並びます" />

| 項目 | 内容 |
|------|------|
| 予約日時 | 開始と終了の時刻 |
| コース | 選んだコース |
| 予約ステータス | 確定・調整中・新規予約・下書き・完了・キャンセル |
| 指名タイプ | 「料金システム」に登録した指名料（例: 本指名、写真指名） |
| 指名キャスト | 担当するキャスト |
| 延長料金・オプション・店舗割引 | 追加したもの。なければ「なし」 |
| 広告 | どの広告を見てのご予約か |
| 予約方法 | LINE・電話などの受付経路 |
| 登録スタッフ | 予約を登録した担当者 |
| ご要望 | お客様からのご要望 |

### 支払い情報を見る
画面の右側に、料金の内訳と合計金額が出ます。割引が入っている場合は、マイナスの金額で表示されます。

<Callout type="warning">
コースや指名を変えると、**料金も自動で変わります。**変更したあとは、必ず「合計金額」を確認してください。すでにお客様にお伝えした金額と違ってしまう場合があります。
</Callout>

### ご案内のSMSを送る
支払い情報のすぐ下に「SMS」のまとまりがあります。ボタンの意味は予約一覧と同じです。

| ボタン | 出る予約 | 押すとどうなるか |
|------|------|------|
| SMSを開く | すべての状態 | お使いの端末のSMSアプリが、状態に合った文面が入った状態で開きます。送信はご自分でSMSアプリ上で行います |
| 予約内容を送信 | 確定のみ | pixi から直接お送りします。送信・開封の記録が残ります |

### 予約を取り消す
1. 「予約内容」の「編集する」を押します
2. 「予約ステータス」を「キャンセル」に変えます
3. 保存します

<Callout type="note">
キャンセルにしても、予約の記録は残ります。売上やレポートからは除かれます。
</Callout>

## 確認ポイント
- 変更したあと、合計金額がお客様にお伝えした金額と合っていること
- 日時を変えたときは、部屋とキャストが空いているか（スケジュール画面で確認できます）

## よくあるミス
- 「編集する」を押さずに直そうとする
- 1つのまとまりを保存しただけで、他のまとまりの変更が保存されていない
- 日時を変えたのに、部屋の空きを確認していない
