# 予約の新規作成

<Callout type="note" title="必要なプラン・権限">
すべてのプランで利用できます。表示される入力項目は「予約フォーム内項目設定」で店舗ごとに変わります。
</Callout>

## できること
- お客様情報 → 施術内容 → お支払いの3ステップで予約を登録できる
- 電話番号から既存の顧客情報を自動で呼び出せる（顧客ルックアップ）
- コース・オプション・指名料・延長・割引から料金内訳を自動計算できる
- 指名キャストの予約が重なる場合や、インターバル（間隔）不足の場合に警告を確認できる

## 事前準備
- 管理画面にログインしていること
- コース・オプション・指名料などの料金システムが登録されていること
- 指名予約の場合、対象キャストが登録されていること

## 手順
### お客様情報を入力する
1. 予約作成画面を開きます（予約一覧やスケジュールの「新規予約を作成」から開けます）
2. 「お客様情報」に、お名前・フリガナ・電話番号などを入力します
3. 電話番号を入力して欄から離れると、登録済みの顧客が自動で検索され、見つかればお名前などが自動入力されます
4. 出禁対象のお客様の場合は、この時点で警告が表示されます

<Figure alt="お客様情報ステップと電話番号による顧客検索" caption="電話番号を入力すると既存の顧客情報を自動で呼び出せます" />

### 施術内容を入力する
1. 「施術内容」で予約日時・指名キャスト・指名タイプ・コースを選びます
2. 必要に応じてオプション・延長・割引・予約方法・広告媒体などを設定します
3. 選択に応じて、お支払いステップの料金内訳が自動で更新されます

<Callout type="warning">
過去の日時は予約日時に指定できません。過去日時を選ぶとエラーが表示されます。
</Callout>

<Figure alt="施術内容ステップ（日時・キャスト・コース・オプション）" caption="コースやオプションを選ぶと料金が自動計算されます" />

### お支払いを確認して確定する
1. 「お支払い」で支払い方法を選びます
2. 料金内訳（コース・オプション・指名料・延長・割引）と合計金額を確認します
3. 「内容を確認する」を押すと、確認画面が開きます
4. 内容を確認し「予約を確定する」を押します

<Callout type="note">
指名キャストを選んでいる場合、確定時にそのキャストの予約重複・インターバル（間隔）をチェックします。予約が重なっている場合は確定できません。インターバル不足の場合は確認モーダルが表示され、そのまま進めるか選べます。指名キャストなし（フリー予約）ではこのチェックは行われません。
</Callout>

<Figure alt="予約内容の確認モーダルと料金内訳" caption="料金内訳と合計を確認してから予約を確定します" />

## 確認ポイント
- 確定後に予約一覧へ戻り、「予約を登録しました」と表示されること
- 登録した予約が一覧・スケジュールに反映されていること

## よくあるミス
- 過去の日時を予約日時に指定してしまう
- 指名キャストの予約が重なっていて確定できない（時間帯を調整してください）
- 電話番号の入力ミスで既存顧客が呼び出せず、二重に顧客が作られる
