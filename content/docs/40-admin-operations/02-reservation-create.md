# 予約を新しく登録する

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご利用いただけます。
</Callout>

## できること
- お電話やLINEで受けたご予約を、管理画面に登録できる
- コース・指名・オプションを選ぶと、料金が自動で計算される
- 割引を入れられる
- いったん「下書き」で保存しておける

## 事前準備
- 管理画面にログインしていること
- コース・指名料・オプションが「料金システム」に登録されていること

## 手順

### 登録画面を開く
1. 画面左のメニューから「予約」を押します
2. 右上の「新規予約を作成」を押します
3. 上から順に入力していきます。**赤い「＊」が付いている項目は必ず入力**します

<Callout type="note">
どの項目を表示するか、どの項目を必須にするかは、**お店ごとに変えられます**（「予約フォーム内項目設定」で設定します）。このため、下の表と実際の画面が違うことがあります。**画面に出ている「＊」が正しい**とお考えください。
</Callout>

### お客様情報を入れる
| 項目 | 必須 | 内容 |
|------|:--:|------|
| 電話番号 | ＊ | 例: 090-1234-5678 |
| お名前 | ＊ | お客様のお名前 |
| フリガナ | お店の設定による | お名前の読みかた（初期設定では任意です） |
| メールアドレス | お店の設定による | 初期設定では表示されません |

<Figure src="/manuals/admin/40-admin-operations/02-reservation-create/01-create-form.jpg" alt="予約登録画面の上部。お客様情報と施術内容の入力欄" caption="上から順に、お客様情報 → 施術内容 → お支払い の順で入力します" />

<Callout type="tip">
すでに登録のあるお客様は、電話番号を入れると残りが自動で入ることがあります。入らない場合は手で入力してください。
</Callout>

### 施術内容を入れる
| 項目 | 必須 | 内容 |
|------|:--:|------|
| 予約日時 | ＊ | 「日付を選択」を押して、日にちと時間を選びます |
| コース | ＊ | 「料金システム」に登録したコースから選びます |
| 指名タイプ | ＊ | 「料金システム」に登録した指名料から選びます（例: 本指名、写真指名） |
| 指名キャスト | お店の設定による | 担当するキャストを選びます |
| 延長料金 | お店の設定による | 延長がある場合のみ選びます |
| オプション | お店の設定による | 追加のオプションがある場合のみ選びます |
| 店舗割引 | お店の設定による | お店の割引を使う場合のみ選びます |
| 予約方法 | ＊ | どの経路で受けたご予約かを選びます（選択肢はお店ごとに設定します） |
| 広告媒体 | お店の設定による | どの広告を見てのご予約かを選びます |
| 予約ステータス | ＊ | 新規予約／下書き／確定／調整中／完了／キャンセル から選びます |
| 登録スタッフ | ＊ | 入力しているあなた（担当者）を選びます |
| ご要望 | | お客様からのご要望を書きます |

<Callout type="note">
「下書き」で保存すると、あとから続きを入力できます。お客様に確定のご連絡をする前の、仮の状態として使います。
</Callout>

### お支払いと料金を確認する
1. 「支払い方法」で「現金」「カード」のどちらかを選びます
2. その下の「料金内訳」に、選んだ内容の金額が自動で出ます
3. 「店舗」と「キャスト」の2列に分かれています。お店の取り分とキャストの取り分です

料金内訳に出る項目は次のとおりです。

| 行 | 内容 |
|------|------|
| コース料金 | 選んだコースの金額 |
| オプション料金 | 選んだオプションの合計 |
| 指名料 | 選んだ指名タイプの金額 |
| 延長料金 | 選んだ延長の金額 |
| 割引（店舗割引） | 選んだ店舗割引の金額 |
| その他 | 上のどれにも入らない金額 |
| 総額 | 店舗・キャストそれぞれの合計 |

<Figure src="/manuals/admin/40-admin-operations/02-reservation-create/02-price-breakdown.jpg" alt="お支払いの欄。支払い方法の選択と、料金内訳の表" caption="選んだコースやオプションに応じて、料金が自動で計算されます" />

<Callout type="warning">
**「カード」を選ぶと、お客様への請求に決済手数料10%が上乗せされます。** 「現金」では上乗せされません。お客様に金額をお伝えするときは、支払い方法が合っているかを先に確認してください。
</Callout>

### 割引を入れる（必要なとき）
1. 「割引（任意）」の欄で、どの項目から割引くかを選びます
2. 割引く金額を入れます
3. 複数入れたいときは「割引を追加」を押します

### 登録する
1. いちばん下の「内容を確認する」を押します
2. 表示された内容を確認して、登録します

<Callout type="warning">
登録する前に、**日時・キャスト・料金**の3点を必ず読み直してください。登録後の変更はできますが、お客様への連絡のやり直しが必要になります。
</Callout>

### 「内容を確認する」で止まったとき
「内容を確認する」を押すと、選んだキャスト・時間について自動でチェックが入ります。次のときは、確認画面に進めません。

| 出るメッセージ | 意味 | 対処 |
|------|------|------|
| 選択した時間帯は既に予約が入っています | 同じキャストに、その時間の予約がすでにある | 別の時間、または別のキャストを選びます |
| シフトを登録していないキャストのため予約を作成できません | その日のシフトが登録されていない | 先に「シフト」でそのキャストのシフトを登録します |
| この日の報酬は確定済みのため予約を作成できません | その日の報酬をすでに確定させている | 「報酬」の詳細画面で確定を取り消してから、もう一度登録します |

次のときは、確認のうえで**そのまま進めます**。

| 出るメッセージ | 意味 |
|------|------|
| 前の予約終了後の休憩時間（インターバル ◯分）に該当する時間帯です | 前後の予約とのあいだに、お店が決めた休憩時間が取れていない |
| 出勤時間を越えるがこのまま予約に進みますか？ | キャストの出勤申請の時間からはみ出している |

進めてよければ「OK」を押します。

## 確認ポイント
- 「お客様請求合計」の金額が、お客様にお伝えした金額と合っていること（カード払いは手数料10%が入ります）
- 指名タイプが正しいこと（料金とキャストの取り分が変わります）
- 選んだキャストが、その時間にシフトを出しているか

## よくあるミス
- 日をまたぐ時間（例: 23:30開始）で、日付を翌日にしてしまう（開始日を選びます）
- 「下書き」のまま保存して、確定にするのを忘れる
- 登録スタッフを選び忘れる（必須項目です）
- カード払いなのに、手数料を含めない金額をお客様にお伝えしてしまう
