# スケジュール（部屋の空き状況）

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご利用いただけます。
</Callout>

## できること
- 部屋ごとの予約の入りぐあいを、時間割の形で確認できる
- 1日・3日・1週間を切り替えて見られる
- キャストごとに色を分けて、誰がどこに入っているか見られる
- 空いている時間を見つけて、その場で予約を作れる

## 事前準備
- 管理画面にログインしていること
- 「ルーム」に部屋が登録されていること

## 手順

### スケジュールを開く
1. 画面左のメニューから「スケジュール」を押します
2. 横方向に部屋（Room A、Room B …）、縦方向に時間が並びます
3. 予約は色の付いた四角で表示されます

<Figure src="/manuals/admin/40-admin-operations/04-schedule/01-schedule.jpg" alt="スケジュール画面。左に日付とキャストの一覧、右に部屋ごとの時間割" caption="横が部屋、縦が時間です。赤い横線が現在の時刻を表します" />

<Callout type="tip">
画面を横切る**赤い線が「今の時刻」**です。今どの部屋が使われているかが、ひと目で分かります。
</Callout>

### 表示する日を変える
1. 画面上部の「＜」「＞」で前の日・次の日に移動します
2. 「今日」を押すと今日に戻ります
3. 左側のカレンダーで、日にちを直接選べます
4. 右上の「日」「3日」「週」で、一度に見る範囲を変えられます

### キャストで色分けする
左側の「キャスト」の欄に、キャストの名前と色が並びます。

1. 名前の左の四角を押すと、そのキャストの表示を消したり出したりできます
2. 「全解除」を押すと、全員の表示を消せます
3. 「もっと見る（◯名）」を押すと、残りのキャストが出ます

### 予約の状態を見分ける
四角の中のバッジで状態が分かります。左側の「ステータス」に一覧があります。

| 表示 | 意味 |
|------|------|
| 確定 | 予約が決まっている |
| 新規 | 入ったばかりで、まだ確認していない |
| 調整中 | 日時などを調整している途中 |
| 完了 | ご利用が終わった |

<Callout type="warning">
**キャンセル・下書き・無断キャンセルの予約は、スケジュールには表示されません。** この4つ以外を探すときは「予約」の一覧で確認してください。
</Callout>

四角の中には、時間・お客様名・コース・金額と、指名の種類（「本指」など）が出ます。出勤申請の時間からはみ出している予約には、黄色い「シフト申請外の対応」が付きます。

### カードの地色（顧客区分）
四角の**地色**は、お客様がはじめてか2回目以降かを表します。左側の「顧客区分」に一覧があります。

| 地色 | 意味 |
|------|------|
| 新規のお客様 | はじめてご来店のお客様 |
| リピーター | 2回目以降のお客様 |

<Callout type="note">
判定できないときは白のままになります。
</Callout>

### 「予約不可」の枠
グレーの斜線が入った「予約不可」の四角は、お客様の予約ではなく、**その時間を埋めておくための枠**です。

- 予約一覧・予約詳細には出ません。時間の変更と削除は、この画面で枠を押して行います

### 空いているところに予約を作る
方法は2つあります。

- 左上の「＋ 新規予約を作成」を押す
- キャストのカードの右上にある「＋」を押す（そのキャストを選んだ状態で登録画面が開きます）

## 確認ポイント
- 部屋が重なって予約されていないこと
- キャストの表示を消したままにしていないこと（消していると、その予約が見えません）
- 探している予約がキャンセル・下書きでないこと（この画面には出ません）

## よくあるミス
- キャストの表示を一部消したままにしていて、予約が入っていないと勘違いする
- 「日」表示のまま翌日の予約を探してしまう（「3日」や「週」に切り替えます）
- 深夜をまたぐ予約を見落とす（下にスクロールすると続きがあります）
