# スケジュール

<Callout type="note" title="必要なプラン・権限">
すべてのプランで利用できます。表示される確定シフトは、シフト管理（pro／ultra）で登録された内容に基づきます。
</Callout>

## できること
- 日／3日／週の各ビューでスケジュールを確認できる
- 前後の移動・今日へ戻る・ミニカレンダーで日付を移動できる
- キャストで絞り込んで表示できる
- 確定シフトと予約を重ねて表示できる
- 予定を押して詳細ポップオーバーを確認できる
- この画面から新規予約を作成できる

## 事前準備
- 管理画面にログインしていること
- 予約やシフトが登録されていること

## 手順
### ビューと日付を切り替える
1. サイドメニューの「スケジュール」を開きます（`/schedule`）
2. 上部のツールバーで「日」「3日」「週」のビューを切り替えます
3. 前後の矢印で移動、「今日」で当日へ戻れます
4. 左のミニカレンダーで任意の日付へ移動できます

<Figure alt="スケジュールのツールバーとミニカレンダー" caption="日／3日／週ビューの切り替えと、日付の移動ができます" />

### キャストで絞り込む
1. 左のキャストフィルターで、表示するキャストを選びます
2. すべて選択／すべて解除でまとめて切り替えられます
3. 選んだキャストの予定だけがカレンダーに表示されます

<Callout type="note">
キャストフィルターには、表示期間内で「確定シフトがある」または「予約がある」キャストが並びます。確定シフトが登録されているキャストは、予約がなくても出勤予定者として表示されます。
</Callout>

<Figure alt="キャストフィルターと確定シフト・予約の重ね表示" caption="キャストごとに、確定シフトと予約を重ねて表示できます" />

### 予定の詳細を確認する
1. カレンダー上の予定（イベント）を押します
2. 詳細ポップオーバーで、指名タイプやステータスなどを確認できます
3. ステータスは色分けされ、凡例（確定・新規・調整中・完了・キャンセル・下書き）で見分けられます

<Figure alt="イベント詳細ポップオーバー" caption="予定を押すと詳細ポップオーバーが表示されます" />

### この画面から新規予約を作成する
1. 左サイドの「新規予約を作成」を押します
2. 選択中の日付が引き継がれた状態で、予約作成画面が開きます
3. 施術内容などを入力して予約を登録します

<Figure alt="スケジュールからの新規予約作成ボタン" caption="選択中の日付を引き継いで新規予約を作成できます" />

## 確認ポイント
- 登録済みの予約・確定シフトがカレンダーに表示されていること
- キャスト絞り込みが意図どおりに効いていること

## よくあるミス
- キャストフィルターで一部しか選んでおらず、他のキャストの予定が見えていない
- 確定シフトが未登録のため、出勤予定者としてキャストが並ばない
