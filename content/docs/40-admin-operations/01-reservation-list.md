# 予約一覧

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご利用いただけます。
</Callout>

## できること
- 今日の予約をカードで、すべての予約を一覧で確認できる
- 状態（確定・調整中など）でしぼり込める
- 日付・時間・コース・キャスト・料金でこまかくしぼり込める
- 一覧の並び順を「登録が新しい順」と「予約日時が新しい順」で切り替えられる
- カードから直接、状態を変えられる
- お客様にご案内のSMSを送れる

## 事前準備
- 管理画面にログインしていること

## 手順

### 今日の予約を確認する
1. 画面左のメニューから「予約」を押します
2. 上半分に「本日の予約」がカードで並びます
3. 見たい状態のボタン（「確定」「調整中」など）を押すと、その状態だけになります
4. 件数が多いときは「もっとみる（残り◯件）」を押します

<Figure src="/manuals/admin/40-admin-operations/01-reservation-list/01-today-reservations.jpg" alt="予約画面の上部。検索欄・状態のボタン・本日の予約のカード" caption="上半分が「本日の予約」です。カードの左端の色が状態を表します" />

カードの左端の色と、右上の表示で状態が分かります。

| 状態 | 色 | 意味 |
|------|:--:|------|
| 確定 | 緑 | 予約が決まっている |
| 調整中 | オレンジ | 日時などを調整している途中 |
| 新規予約 | 青 | 入ったばかりで、まだ確認していない |
| 下書き | グレー | 作りかけで、まだ確定していない |
| 完了 | 紺 | ご利用が終わった |
| キャンセル | 赤 | 取り消された |

### 状態を変える
1. カードの右上にある状態の表示（「確定」など）の横の「⌄」を押します
2. 変えたい状態を選びます

### ご案内のSMSを送る
SMSのボタンは**2つ**あり、役割が違います。

| ボタン | 出る予約 | 押すとどうなるか |
|------|------|------|
| SMSを開く | すべての状態 | お使いの端末のSMSアプリが、状態に合った文面が入った状態で開きます。**送信はご自分でSMSアプリ上で行います** |
| 予約内容を送信 | 確定のみ | pixi から直接お送りします。送ったあと、表示が「送信済み」に変わります |

1. 「予約内容を送信」を押します
2. 表示が「送信済み」に変わります
3. お客様がSMSを開くと「開封済み」に変わります

<Callout type="warning">
「SMSを開く」で送った分は、pixi 側に記録が残りません。「送信済み」「開封済み」の表示は、**「予約内容を送信」で送った分だけ**変わります。
</Callout>

<Callout type="note">
「送信済み」「開封済み」になったあとでも、同じボタンをもう一度押せば送り直せます。
</Callout>

### すべての予約から探す
画面を下にスクロールすると「予約一覧」があります。今日以外の予約もここで探せます。

1. 上のボタンで状態をしぼり込みます
2. 検索欄に、予約名・コース名・ルーム名のいずれかを入れます
3. 右端の「↗」を押すと、その予約の詳しい画面が開きます

<Figure src="/manuals/admin/40-admin-operations/01-reservation-list/02-reservation-table.jpg" alt="画面下部の予約一覧。並び順の選択欄・状態のボタン・検索欄・フィルターのボタン・予約の行" caption="「予約一覧」では今日以外の予約も探せます。右端の矢印で詳細が開きます" />

<Callout type="tip">
一覧の右上に「28件中 1〜10件表示」のように件数が出ます。しぼり込みが効いているかどうかは、ここで確認できます。
</Callout>

### こまかくしぼり込む
検索欄の右にあるボタン（横棒とつまみのマーク）を押すと、「予約一覧フィルター」が開きます。

| 項目 | 指定できること |
|------|------|
| ステータス | 確定・調整中などの状態（複数選べます） |
| 日付 | 開始日と終了日。「全期間に戻す」で解除できます |
| 開始時間 | 予約の開始時刻の下限と上限（30分きざみ） |
| コース | コース名（文字を入れてしぼり込みます） |
| キャスト | 登録済みのキャストから選びます |
| 料金範囲 | 最小金額と最大金額 |

1. しぼり込みたい項目を指定します
2. 下の「◯件の結果を表示」を押すと閉じて、一覧に反映されます
3. 解除したいときは、左下の「クリア」を押します

<Callout type="tip">
しぼり込みが効いているときは、フィルターの上部に「◯件適用中」と出ます。「探している予約が出てこない」ときは、まずここを確認してください。
</Callout>

### 並び順を変える
「予約一覧」の見出しの横にある選択欄で、並び順を変えられます。

| 並び順 | 使いどころ |
|------|------|
| 登録が新しい順（初期値） | いま登録した予約を先頭で確認したいとき |
| 予約日時が新しい順 | 予約日の近い順に見ていきたいとき |

### 新しい予約を作る
画面右上の「新規予約を作成」を押します。作り方は次の節で説明します。

## 確認ポイント
- 状態のしぼり込みを解除するときは「すべて」を押すこと
- 「予約内容を送信」を押したあと、表示が「送信済み」に変わっていること
- 黄色い「シフト申請外の対応」が付いた予約は、キャストの出勤申請の時間からはみ出しています

<Callout type="note">
「シフト申請外の対応」は、出勤申請が登録されている日にだけ判定できます。**バッジが出ていないことは「シフト内」という意味ではありません。**
</Callout>

## よくあるミス
- 状態やフィルターでしぼり込んだままになっていて、探している予約が出てこない
- 「本日の予約」だけを見て、翌日以降の予約を見落とす（下の「予約一覧」で確認します）
- 「SMSを開く」で送ったのに、「送信済み」にならないと思ってしまう（記録が残るのは「予約内容を送信」だけです）
- 日をまたぐ予約（例: 23:30 - 翌1:30）を、翌日の予約だと思ってしまう
