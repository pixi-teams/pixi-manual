# 請求（pixi のご利用料金）

<Callout type="note" title="必要なプラン・権限">
どのご契約でもご利用いただけますが、「請求を見せる」設定になっているスタッフだけが利用できます。
</Callout>

## できること
- pixi のご利用料金の明細を、月ごとに確認できる
- 入金の状況（未入金・期日超過・入金済み）を確認できる
- 請求書と領収書をダウンロードできる

<Callout type="note">
ここに出るのは、**お店が pixi にお支払いいただくご利用料金**です。お客様への請求ではありません。
</Callout>

## 事前準備
- 管理画面にログインしていること
- 自分に「請求」の表示が許可されていること

## 手順

### 請求一覧を開く
1. 画面左のメニューから「請求」を押します
2. 画面の上に「8件・合計 ￥412,000」のように、件数と合計が出ます

<Figure src="/manuals/admin/60-admin-accounting/04-billing/01-billing-list.jpg" alt="請求一覧の表。利用月・発行日・金額・期日・入金状況・書類" caption="月ごとの明細と、入金の状況が並びます" />

一覧には次の内容が出ます。

| 列 | 内容 |
|------|------|
| 利用月 | どの月のご利用分か |
| 発行日 | 請求書を発行した日 |
| 金額 | ご請求金額 |
| 期日 | お支払いの期限 |
| ステータス | 入金の状況 |
| 書類 | 請求書・領収書のダウンロード |

### 入金の状況を見分ける

| 表示 | 色 | 意味 |
|------|:--:|------|
| 未入金 | オレンジ | まだお支払いいただいていない（期日前） |
| 期日超過 | 赤 | 期日を過ぎてもお支払いがない |
| 入金済み | 緑 | お支払いが確認できている |

<Callout type="warning">
「期日超過」が出ている場合は、お早めにお支払いください。放置するとサービスのご利用に影響する場合があります。
</Callout>

### しぼり込む
画面の上のボタンで「すべて」「未入金」「期日超過」「入金済み」を切り替えられます。

### 請求書・領収書を受け取る
1. 一覧の右側にある「請求書」を押すと、請求書がダウンロードされます
2. お支払いが済んでいる月は「領収書」も押せます

<Callout type="note">
まだお支払いいただいていない月は、「領収書」のボタンが灰色になっていて押せません。入金が確認できると押せるようになります。
</Callout>

## 確認ポイント
- 「未入金」「期日超過」が残っていないか
- 経理処理に必要な請求書・領収書をダウンロードしたか

## よくあるミス
- お客様への請求と取り違える（ここは pixi のご利用料金です）
- しぼり込んだままにしていて、他の月の明細が見えていない
