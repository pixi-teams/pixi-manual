# 経費

<Callout type="note" title="必要なプラン・権限">
経費メニューは、スタッフの「経費」表示設定（showExpense）が有効になっている場合に利用できます。
</Callout>

## できること
- 登録済みの経費を一覧で確認できる
- 項目名またはキャスト名で検索できる
- 日付の範囲で絞り込める
- 対象期間の合計金額を確認できる
- 新規経費を登録できる
- 経費の行を押して詳細を確認できる

## 事前準備
- 管理画面にログインしていること
- スタッフの「経費」表示設定が有効になっていること

## 手順

### 経費を探す
1. サイドメニューの「経費」を開きます
2. 検索ボックスに項目名またはキャスト名を入力します
3. 開始日・終了日の日付ピッカーで期間を絞り込みます（クリアするとフィルターを解除できます）
4. 見出し下で件数と合計金額を確認します

<Figure alt="経費一覧の検索・日付フィルターと合計金額" caption="検索と日付フィルターで絞り込み、合計金額を確認します" />

### 新規登録する
1. 一覧右上の「新規登録」を押します（/expenses/new に進みます）
2. 経費の内容を入力して登録します

<Figure alt="経費の新規登録画面" caption="経費の内容を入力して登録します" />

## 確認ポイント
- 日付フィルターを設定したとき、合計金額が対象期間の内容に合っていること
- 登録した経費が一覧に表示されていること

## よくあるミス
- 「経費」表示設定が無効なスタッフでメニューが見えないと問い合わせる（表示設定を確認します）
- 日付フィルターを設定したままで、想定より件数が少なく見える（フィルターをクリアして確認します）
