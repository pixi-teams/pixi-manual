# レポート（売上の集計）

<Callout type="note" title="必要なプラン・権限">
pro／ultra のご契約で、かつ「レポートを見せる」設定になっているスタッフだけが利用できます。
</Callout>

## できること
- 日・週・月ごとの売上と予約数を確認できる
- 売上・報酬・店落ちの内訳を確認できる
- 時間帯ごとの売上と来客数をグラフで確認できる
- 支払い方法ごとの内訳を確認できる
- 出勤したキャスト数や平均の接客数を確認できる

## 事前準備
- 管理画面にログインしていること
- pro／ultra のご契約であること
- 自分に「レポート」の表示が許可されていること

## 手順

### レポートを開く
1. 画面左のメニューから「レポート」を押します
2. 画面の上に日付、その下に「日」「週間」「月間」の切り替えがあります

<Figure src="/manuals/admin/60-admin-accounting/01-report/01-report.jpg" alt="レポート画面。上に4つの数字、下に時間帯別売上と決済別売上のグラフ" caption="上の4つで全体を、下のグラフで内訳を確認します" />

### 期間を切り替える
1. 「日」「週間」「月間」のいずれかを押します
2. 上部の「＜」「＞」で、前の期間・次の期間に移動します

### 4つの数字を見る
画面の上に、その期間の合計が4つ並びます。

| 表示 | 意味 |
|------|------|
| 売上合計 | お客様からいただいた金額の合計 |
| 報酬合計 | キャストにお支払いする金額の合計 |
| 店落ち合計 | 売上からキャストの報酬を引いた、お店の取り分 |
| 予約数 | その期間の予約の件数 |

それぞれの下に「前日比」などの増減が出ます。緑が増加、赤が減少です。

<Callout type="note">
**売上合計 −  報酬合計 = 店落ち合計** です。ダッシュボードに出ている「店落ち」と同じ数字です。
</Callout>

### 内訳を見る
画面の下に、内訳のグラフが並びます。

| グラフ | 分かること |
|------|------|
| 時間帯別売上 | どの時間帯によく売れているか（新規客とリピータ客で色分け） |
| 時間帯別来客数 | どの時間帯にお客様が多いか（同じく色分け） |
| 決済別売上 | 支払い方法ごとの内訳 |
| 稼働サマリー | 人と部屋がどれだけ動いたか（下の表） |

<Callout type="tip">
「時間帯別来客数」を見ると、シフトを厚くすべき時間帯が分かります。シフトを組むときの目安に使えます。
</Callout>

### 稼働サマリーの4つの数字
| 表示 | 意味 |
|------|------|
| 出勤キャスト数 | その期間に出勤したキャストの人数 |
| 平均接客数 | キャスト1人あたりの接客件数 |
| 出勤率 | 在籍キャストのうち、どれだけが出勤したか |
| ルーム稼働率 | 部屋がどれだけ使われたか |

<Callout type="warning">
この4つは、すべて**シフト（出勤申請）の登録をもとに計算**しています。予約だけ入れてシフトを登録していないと、**予約があっても 0 と表示されます。**数字がおかしいときは、まずシフトが登録されているかを確認してください。
</Callout>

## 確認ポイント
- 期間の切り替え（日／週間／月間）が、見たいものに合っているか
- 日付が正しいか（「＜」「＞」で動かしたまま戻し忘れていないか）

## よくあるミス
- 「日」表示のまま月の売上を見ようとする
- 「売上合計」をお店の利益と勘違いする（お店の取り分は「店落ち合計」です）
- レポートのメニューが出ないとき、契約ではなく個別の表示設定が原因のことがある
