# 料金システム

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご利用いただけます。ここで登録した内容が、予約の登録画面とWeb予約の選択肢になります。
</Callout>

## できること
- コース・オプション・指名料・延長料金・割引を登録できる
- それぞれについて、キャストの取り分とお店の取り分を決められる
- お客様に見せる・見せないを切り替えられる

## 事前準備
- 管理画面にログインしていること

## 手順

### 料金システムを開く
1. 画面左のメニューから「料金システム」を押します
2. 種類ごとのまとまりが縦に並びます。画面の上に「22件の料金項目を管理中」のように件数が出ます

<Figure src="/manuals/admin/60-admin-accounting/05-pricing/01-pricing.jpg" alt="料金システムの画面。お試しコースと通常コースの表" caption="種類ごとにまとまっています。それぞれ「追加」で項目を増やせます" />

まとまりは上から順に次の6種類です。

| まとまり | 内容 |
|------|------|
| お試しコース | 初めてのお客様向けの特別価格 |
| 通常コース | ふだんのコース |
| オプション | コースに追加できるもの |
| 指名料 | ご指名にかかる料金 |
| 延長料金 | 規定の時間を超えた分の料金 |
| 割引 | 料金から差し引くもの |

### 表の見かた
コースの表には次の列があります。

| 列 | 意味 |
|------|------|
| ステータス | 公開（お客様に見せる）／非公開（見せない） |
| コース名 | お客様に表示される名前 |
| 料金 | お客様からいただく金額 |
| 時間 | ご利用時間 |
| キャスト | そのうちキャストにお支払いする金額 |
| 店舗 | そのうちお店に入る金額 |

<Callout type="warning">
**「キャスト」の欄が、報酬の計算のもとになります。**ここが未設定だと、報酬の画面で0円になります。コースを追加したら必ず設定してください。
</Callout>

### 項目を追加する
1. まとまりの右上にある「＋ 追加」を押します
2. 名前・料金・時間・キャストの取り分を入れます
3. 登録します

### 公開・非公開を切り替える
- **1件ずつ**: 表の「ステータス」で切り替えます。6つのまとまりすべてでできます
- **まとまりごと**: 見出しの横の「公開」の表示で、そのまとまり全体を切り替えます。これができるのは**「お試しコース」と「通常コース」の2つだけ**です

<Callout type="tip">
季節限定のコースなどは、削除せず「非公開」にしておくと、また使いたいときにすぐ戻せます。過去の予約の記録も残ります。
</Callout>

### まとまりの説明を変える
見出しの横の「編集する」を押すと、そのまとまりの名前と説明文を変えられます。この説明はお客様のWeb予約ページにも出ます。

<Callout type="note">
「編集する」が出るのは「お試しコース」と「通常コース」だけです。オプション・指名料・延長料金・割引の見出しは変えられません。
</Callout>

### 指名料について
指名料の名前は、**お店で自由に決められます。**決まった種類から選ぶ形ではありません。

よく使われるのは「本指名」「写真指名」などですが、お店の運用に合わせて名前を付けてください。

<Callout type="warning">
ここに登録した指名料が、そのまま**予約を登録するときの「指名タイプ」の選択肢**になります。登録していないと、予約画面で指名を選べません。
</Callout>

<Callout type="note">
名前をあとから変えると、これから登録する予約に反映されます。過去の予約には、登録した時点の名前が残ります。
</Callout>

### 延長料金について
延長時間は**分数**で入力します（例: 30）。「30分」ではなく「30」と入れてください。

## 確認ポイント
- 追加したコースの「キャスト」の金額が入っていること
- お客様に見せたくない項目が「非公開」になっていること
- 変更後、実際に「予約」→「新規予約を作成」で選べるようになっているか

## よくあるミス
- キャストの取り分を設定し忘れて、報酬が0円になる
- 延長時間に「30分」と単位まで入れてしまう（分数だけを入れます）
- 非公開にしたつもりが、まとまり全体は公開のままになっている
