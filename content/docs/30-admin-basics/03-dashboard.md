# ダッシュボード（最初の画面）

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご覧いただけます。
</Callout>

## できること
- ログインしたあと最初に開く画面で、今日の状況をひと目で確認できる
- 今日出勤しているキャストと、何時からご案内できるかを確認できる
- エリアやルームでしぼり込んで確認できる
- 店落ちの金額を、今日・前日・今週・今月の4つで確認できる
- SNS に貼りつける出勤情報の文面を、その場で作れる

## 事前準備
- 管理画面にログインしていること

## 手順

### 今日の状況を確認する
1. 画面左のメニューから「ダッシュボード」を押します（ログインした直後は、この画面が開いています）
2. 画面の上に今日の日付が出ます
3. その下の「案内情報」に、今日出勤しているキャストが並びます

<Figure src="/manuals/admin/30-admin-basics/03-dashboard/01-dashboard-top.jpg" alt="ダッシュボードの上部。日付と、出勤しているキャストの一覧" caption="今日の日付と、今日ご案内できるキャストが並びます" />

キャスト1人ずつのカードには、次の内容が出ます。

| 表示 | 意味 |
|------|------|
| 六本木・新宿・渋谷 など | そのキャストのエリア |
| 時間（例: 18:00 - 8/17(月) 1:00） | 今日の出勤時間。日をまたぐ場合は翌日の日付が付きます |
| 最短 19:00〜 | いちばん早くご案内できる時間 |
| 受付終了 | 今日はもう受け付けられない |
| NEW | 新しく入ったキャスト |
| 人気 | 人気のキャスト |
| X・Instagram などのマーク | そのキャストのSNS |

### 表示するキャストをしぼり込む
1. 右上の「すべて」「最短時間」「新人」を押すと、並べ方を変えられます
2. 「エリア」「ルーム」の欄を押すと一覧が開くので、見たいものを選びます
3. 人数が多いときは、下の「もっと見る（残り◯名）」を押すと続きが出ます

<Figure src="/manuals/admin/30-admin-basics/03-dashboard/02-store-guide-filter.jpg" alt="「エリア」の選択欄を押して一覧が開いたところ" caption="「エリア」や「ルーム」を押すと選べる一覧が開きます" />

### 店落ちを確認する
キャストの一覧の下に、4つのまとまりが並びます。

1. 画面を下にスクロールします
2. 「Today（今日）」「前日」「今週」「今月」の4つが並びます
3. それぞれに店落ちの金額と、ひとつ前の期間とくらべた増減が出ます

<Figure src="/manuals/admin/30-admin-basics/03-dashboard/03-summary-cards.jpg" alt="今日・前日・今週・今月の店落ちの金額" caption="店落ちの金額と、前の期間とくらべた増減が出ます" />

<Callout type="note">
増減の色は、増えていれば緑、減っていれば赤で出ます。
</Callout>

### SNSに貼る文面を作る
店落ちのまとまりの下に「SNS投稿」があります。出勤情報や案内状況の文面が自動で作られるので、コピーしてそのまま投稿できます。

1. 「本日の出勤情報」または「只今の案内状況」の枠を見ます
2. 内容を直したいときは、枠の中の文字をそのまま書き換えられます
3. 「コピー」を押すと、文面がコピーされます
4. 「投稿する」を押すと、SNSの投稿画面が開きます
5. 元に戻したいときは「リセット」を押します

<Callout type="tip">
「すべて見る」を押すと、出勤しているキャスト全員が文面に入ります。
</Callout>

## 確認ポイント
- 画面の上に、今日の日付が正しく出ていること
- SNSに投稿する前に、文面の内容をひととおり読み直すこと

## よくあるミス
- エリアやルームでしぼり込んだままになっていて、一部のキャストしか出ていないことに気づかない
- SNSの文面を直したあと「コピー」を押さずに投稿画面へ進んでしまう
