# ログイン

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご利用いただけます。ログインには、お店ごとに決められた「ストアコード」が必要です。
</Callout>

## できること
- ストアコード・ユーザーID（またはメールアドレス）・パスワードを入れて、管理画面に入れる
- Google のアカウントでも入れる
- パスワードを忘れたときに、自分で再設定できる
- 一度入っておけば、しばらくの間は入り直さなくてよい

## 事前準備
次の3つが手元にあることを確認してください。すべてお店の担当者からお渡ししています。

| 必要なもの | どんなもの | 画面での表示 |
|------|------|------|
| ストアコード | お店ごとに決まっている文字列（例: `my-shop-1`） | Store Code |
| ユーザーID または メールアドレス | あなた個人のもの | User ID or Email |
| パスワード | あなた個人のもの | Password |

<Callout type="note">
pixi の管理画面は「1回のログインにつき、1つのお店」です。ログインしたあとにお店を切り替える画面はありません。複数のお店を運営している場合は、お店ごとのストアコードで入り直してください。
</Callout>

## 手順

### IDとパスワードで入る
1. インターネットを見るアプリ（Google Chrome や Safari など）で、お店のログイン画面を開きます
2. 画面の右半分に入力欄が3つ並びます。「Store Code」にお店のストアコードを入れます
3. 「User ID or Email」に、あなたのユーザーIDまたはメールアドレスを入れます
4. 「Password」に、パスワードを入れます
5. 「Log in」のボタンを押します

<Figure src="/manuals/admin/30-admin-basics/01-login/01-login-form.jpg" alt="ログイン画面に3つの項目を入力したところ" caption="画面の右半分に入力欄があります。上から順に入れて「Log in」を押します" />

<Callout type="tip">
「Password」の欄は、入れた文字が黒い丸で隠れます。右側の目のマークを押すと、入れた文字をそのまま表示して確認できます。
</Callout>

### Google のアカウントで入る
ふだん使っている Google のアカウントでも入れます。パスワードを覚えておく必要がありません。

1. 先に「Store Code」の欄に、お店のストアコードを入れます
2. 「Or Log in with」の下にある「Google で続行」を押します
3. 画面の案内にしたがって、アカウントを選びます

<Figure src="/manuals/admin/30-admin-basics/01-login/02-social-login.jpg" alt="ストアコードだけを入れた状態のログイン画面と、「Google で続行」のボタン" caption="この方法でも、先にストアコードを入れておく必要があります" />

<Callout type="warning">
このアカウントは、あらかじめお店に登録されている必要があります。押しても入れない場合は、お店の担当者にご相談ください。
</Callout>

### パスワードを忘れたとき
1. ログイン画面のいちばん下にある「パスワードを忘れた方はこちら」を押します
2. 「パスワードの再発行」の画面が開きます
3. 登録しているメールアドレスを入れます
4. 「再設定メールを送信」を押します
5. 届いたメールの中のリンクを押して、新しいパスワードを決めます

<Figure src="/manuals/admin/30-admin-basics/01-login/03-forgot-password.jpg" alt="パスワードの再発行画面。メールアドレスの入力欄と送信ボタン" caption="登録しているメールアドレス宛に、再設定用のリンクが届きます" />

<Callout type="note">
メールが届かないときは、迷惑メールに入っていないかご確認ください。それでも届かない場合は、そのアドレスが登録されていない可能性があります。お店の担当者にご相談ください。
</Callout>

## 確認ポイント
- ログインできると、最初の画面（ダッシュボード）が表示されます
- すでにログインしている状態でログイン画面を開くと、自動で最初の画面に戻ります

## よくあるミス
- ストアコードを入れずに「Google で続行」を押してしまう（ストアコードは必ず必要です）
- ストアコードの打ち間違い（アルファベットのオー`o`と数字のゼロ`0`などにご注意ください）
- パスワードが変更されているのに、前のパスワードを入れている
