# マイページとお知らせ

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご利用いただけます。ただしパスワードの変更ができるのはオーナーだけです。
</Callout>

## できること
- 自分のログイン情報（ストアコード・店舗ID）を確認し、パスワードを変更できる
- お店の予約対応の件数と、これまでの履歴を確認できる
- 受け取るお知らせの種類を、ひとつずつオン・オフできる
- 画面右上のベルのマークから、届いたお知らせを読める

## 事前準備
- 管理画面にログインしていること

## 手順

### マイページを開く
1. 画面の右上にある、自分の名前が出ている部分を押します
2. 出てきた中から「マイページ」を選びます
3. 自分の名前と、オーナー／スタッフのどちらかが表示されます

<Figure src="/manuals/admin/30-admin-basics/04-mypage-notifications/01-mypage-top.jpg" alt="マイページの画面。名前と権限、その下に対応件数" caption="ログインしている人の名前と立場（オーナー／スタッフ）が出ます" />

### ログイン情報を確認する
1. 「アカウント」の行を押すと、下に開きます
2. ストアコードと店舗IDが表示されます
3. パスワードを変えたいときは「パスワードを変更する」を押します

<Figure src="/manuals/admin/30-admin-basics/04-mypage-notifications/02-account-section.jpg" alt="アカウントを開いたところ。ストアコード・店舗ID・パスワードを変更するボタン" caption="ストアコードと店舗IDを確認できます。パスワードはボタンから変更します" />

<Callout type="note">
**今のパスワードをこの画面で見ることはできません。**忘れてしまった場合は、ここから変更するか、ログイン画面の「パスワードを忘れた方はこちら」をお使いください。
</Callout>

<Callout type="warning">
パスワードを変えられるのはオーナーだけです。変更したいときはオーナーにご依頼ください。
</Callout>

### 受け取るお知らせを選ぶ
1. 「通知」の行を押すと、下に開きます
2. お知らせは**5つのまとまり**に分かれています。まとまりの行を押すと、中の項目が開きます
3. 受け取りたいものを、右側のスイッチで切り替えます（青色が受け取る、灰色が受け取らない）
4. 押した時点で保存されます。保存ボタンを押す必要はありません

<Figure src="/manuals/admin/30-admin-basics/04-mypage-notifications/03-notification-settings.jpg" alt="通知を開いたところ。5つのまとまりが並んでいる" caption="まとまりの右に「7/7 ON」のように、いくつ受け取る設定かが出ます" />

受け取れるお知らせは次の5つのまとまりです。

| まとまり | 中に入っているもの |
|------|------|
| 予約関連 | Web予約／キャスト・スタッフが作った新規予約／予約内容の変更／予約キャンセル |
| シフト関連 | キャストのシフト申請・変更・削除／他スタッフのシフト削除／空きシフトの作成・確定 |
| 給与関連 | キャストの報酬確定 |
| 店舗・キャスト管理関連 | 他スタッフが登録したキャスト・スタッフ |
| チャット関連 | チャットのメッセージ（ultra のご契約のみ） |

<Callout type="tip">
まとまりの右に出る「7/7 ON」は、そのまとまりの何項目を受け取る設定にしているかを表します。ここを見れば、開かなくても設定の状況が分かります。
</Callout>

### 届いたお知らせを読む
1. 画面の右上にあるベルのマークを押します。まだ読んでいないものがあると、赤い数字が出ます
2. お知らせを押すと、関係する画面に移り、そのお知らせは「読んだ」状態になります
3. 「すべて既読」を押すと、まとめて「読んだ」状態にできます

<Figure src="/manuals/admin/30-admin-basics/04-mypage-notifications/04-notification-dropdown.jpg" alt="ベルのマークを押してお知らせの一覧が開いたところ" caption="ベルのマークを押すと、届いたお知らせが新しい順に並びます" />

<Callout type="tip">
お使いのパソコンやスマートフォンによっては、この一覧の下に「プッシュ通知」の切り替えが出ます。オンにすると、pixi の画面を開いていなくてもお知らせが届くようになります。
</Callout>

## 確認ポイント
- スイッチを切り替えたあと、画面を開き直しても設定が残っていること
- ベルのマークの赤い数字が、読んだあとに減っていること

## よくあるミス
- スタッフの方がマイページからパスワードを変えようとする（変更できるのはオーナーだけです）
- 今のパスワードをこの画面で確認しようとする（表示する機能はありません）
- お使いの機種によっては「プッシュ通知」の切り替えが出ないことがあるのに、故障だと思ってしまう
