# Web予約

## できること
- スマホやパソコンから、24時間いつでもご予約いただけます
- お気に入りのセラピストを指名して予約できます（指名なしの「フリー」予約に対応している店舗もあります）
- 空いている日時をその場で確認しながら予約できます
- 数分・数ステップで予約が完了します

<Callout type="note">
会員登録・ログインは不要です。店舗からご案内された予約ページのURLを開くだけでご利用いただけます。
</Callout>

## ご利用の前に
ご予約には次のものだけご用意ください。

- 店舗からご案内された**予約ページのURL**（例: `https://（店舗ドメイン）/店舗コード`）
- 連絡のつく**携帯電話番号**
- （店舗によっては）**メールアドレス**

<Callout type="warning">
予約ページのURLは**店舗ごとに異なります**。複数の店舗をご利用の場合は、予約したい店舗のURLを開いているかご確認ください。
</Callout>

## 予約の流れ
ご予約は、1つのページ内で次の4ステップを順に進めるだけで完了します。

1. **キャスト** … 来店日と担当セラピストを選ぶ
2. **お時間** … 空いている時間を選ぶ
3. **コース** … コースとオプションを選ぶ
4. **顧客情報** … お名前・電話番号などを入力し、内容を確認して確定

<Figure alt="予約ページの全体像（4ステップの進捗バー）" caption="ページ上部に「キャスト → お時間 → コース → 顧客情報」の進捗が表示されます" />

各ステップの詳しい操作は「[予約の手順](./02-booking-flow)」をご覧ください。

## 確認ポイント
- 最後まで進むと「**ご予約が完了しました**」という画面が表示されます。これで受付完了です
- ご予約後は、店舗の担当者から折り返しご連絡します。連絡をお待ちください

<Callout type="note">
**予約番号は発行されません。** 控えを取っておく必要はなく、店舗からのご連絡をお待ちいただければ大丈夫です。
</Callout>

## よくあるミス
- **別の店舗のURLで予約してしまう** … 予約ページは店舗ごとに分かれています。予約したい店舗のURLを開いてください
- **電話番号の入力形式** … 携帯電話番号（070・080・090で始まる番号）を**半角数字**で入力してください。固定電話や全角数字は登録できません
- **満枠・お休みの日を選んでしまう** … その日に空きがない場合は、別の日を選び直してください
