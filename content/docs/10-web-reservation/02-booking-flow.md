# 予約の手順

## できること
- 4つのステップで、指名予約・フリー予約を完了できます
- コース・オプションの**合計金額を確認してから**予約を確定できます

## ご利用の前に
- 店舗からご案内された予約ページのURLを開いてください（ログイン不要）

## 手順
予約ページ上部の進捗バー（キャスト → お時間 → コース → 顧客情報）に沿って、順に進めます。前のステップには戻ってやり直せます。

### 1. 日付とキャストを選ぶ
1. カレンダー、または「前の日／次の日」ボタンで**来店日**を選びます
2. 一覧から担当してほしい**セラピストを1名**タップします
3. 指名しない場合は、末尾の「**フリー**」を選びます（フリー予約に対応している店舗のみ表示されます）
4. 「次へ」をタップします

<Callout type="tip">
エリアで絞り込める店舗では、キャスト一覧の上にエリア選択が表示されます。表示されない店舗ではそのまま一覧からお選びください。
</Callout>

<Figure alt="ステップ1：日付とキャストの選択画面" caption="来店日を選び、担当セラピストを1名タップします" />

### 2. 時間を選ぶ
1. 選んだセラピストの空いている**開始時間を1つ**タップします
2. 予約済み・受付できない時間は選べません
3. お休みや満枠の日は、日付を選び直してください
4. 「次へ」をタップします

<Figure alt="ステップ2：時間の選択画面" caption="空いている開始時間を1つ選びます" />

### 3. コース・オプションを選ぶ
1. **コースを1つ**選びます（必須）
2. **オプション**は必要な数だけ選べます（任意・複数可）
3. 選ぶと**合計金額**がその場で表示されます
4. 「次へ」をタップします

<Figure alt="ステップ3：コース・オプションの選択画面" caption="コースは1つ必須、オプションは任意で複数選べます" />

### 4. お客様情報を入力して確定する
次の項目を入力します。

- **お名前**（必須）
- **お電話番号**（必須）
- **メールアドレス**（店舗によって必須または任意）
- **当店を知ったきっかけ**（アンケートを行っている店舗のみ表示・必須）
- **ご要望など**（任意・自由記述）

<Callout type="warning">
お電話番号は、**070・080・090で始まる携帯電話番号**を**半角数字（11桁）**で入力してください。固定電話番号や全角数字は登録できません。
</Callout>

1. 入力できたら「**予約を確認する**」をタップします
2. **確認画面（モーダル）**に、日時・キャスト・コース・オプション・指名料・合計金額が表示されます
3. 内容に間違いがなければ、そのまま**確定**します
4. 「**ご予約が完了しました**」画面が表示されれば受付完了です

<Figure alt="ステップ4：お客様情報の入力画面と確認モーダル" caption="内容を確認してから予約を確定します" />

## 予約後の変更・キャンセルについて
<Callout type="warning">
**Web予約サイト上では、予約の変更・キャンセルはできません。** ご予約内容の変更やキャンセルをご希望の場合は、**店舗へお電話**でご連絡ください。
</Callout>

- マイページ・ログイン・予約履歴の機能はありません
- ご予約後は、店舗の担当者から折り返しご連絡します

## 確認ポイント
- 確認画面（モーダル）の**日時・コース・合計金額**がご希望どおりか
- 最後に「**ご予約が完了しました**」画面が表示されたか

## よくあるミス
- **確認画面を閉じただけで予約したつもりになる** … 確認画面で「確定」まで進み、「ご予約が完了しました」画面が出て初めて受付完了です
- **電話番号の入力形式** … 携帯電話番号を半角数字で入力してください（固定電話・全角は不可）
- **予約をサイトで変更・キャンセルしようとする** … Web上ではできません。店舗へお電話ください
