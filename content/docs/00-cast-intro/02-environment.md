# 動作環境

キャストアプリはブラウザで利用します。アプリストアからのインストールは不要です。

## 必須環境
| 項目 | 条件 |
|------|------|
| 端末 | スマートフォン（iPhone / Android）または PC |
| ブラウザ | Safari / Google Chrome の最新版 |
| ネットワーク | インターネットに接続できること |
| JavaScript | 有効であること |
| Cookie | 有効であること（ログイン状態の保持に使用します） |

## 推奨環境
| 項目 | 推奨 |
|------|------|
| 端末 | スマートフォン（普段お使いのもの） |
| ブラウザ | iPhone は Safari、Android は Google Chrome |
| 回線 | 安定した通信環境 |

<Callout type="tip">
ホーム画面に追加しておくと、アプリのように 1 タップで開けます。追加のしかたは「通知とホーム画面への追加」を参照してください。
</Callout>

## 通知について
新しい予約やシフトのお知らせを受け取るには、ブラウザの通知を許可する必要があります。

<Callout type="warning">
端末側で通知をオフにしていると、許可していてもお知らせが届きません。届かない場合は、端末の設定もあわせてご確認ください。
</Callout>

## プライベートブラウズ利用時の注意
プライベートブラウズ（シークレットモード）では、ログイン状態が保持されず、毎回ログインが必要になります。通常のモードでご利用ください。
