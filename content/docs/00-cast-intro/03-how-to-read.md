# 本マニュアルの見かた

## 記事の構成
本書の各記事（節）は、次の 5 つの見出しで統一しています。急いでいるときは「手順」だけ読めば操作できます。

| 見出し | 内容 |
|------|------|
| できること | その画面で何ができるかの一覧 |
| 事前準備 | 操作を始める前に必要な状態 |
| 手順 | 実際の操作。番号のとおりに進めれば完了します |
| 確認ポイント | 操作後に見ておくべきこと |
| よくあるミス | 実際に起きやすい間違いと、その回避方法 |

## 注記の種類
本文中には 4 種類の注記が登場します。枠の左端のラベルで見分けてください。

<Callout type="note" title="メモ">
補足情報です。読み飛ばしても操作は進められます。
</Callout>

<Callout type="tip" title="ヒント">
より効率よく操作するためのコツです。
</Callout>

<Callout type="warning" title="注意">
間違えると取り消せない操作や、お店に連絡が必要になる操作です。必ずお読みください。
</Callout>

<Callout type="step" title="手順">
複数の操作をまとめて示すときに使います。
</Callout>

## スマホとPCで表示が違います
キャストアプリは、スマートフォンでは画面下部のメニュー、PC では左側のサイドバーから各画面に移動します。
本書では「スマホは下部メニューの『シフト』、PC はサイドバーの『シフト』を押します」のように、両方の場合を併記しています。
