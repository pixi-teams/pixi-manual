# 用語説明

本書で使う主な用語をまとめます。

## 予定に関する用語
| 用語 | 説明 |
|------|------|
| スケジュール | その日の稼働予定。出勤時間や予約の入り具合を確認できます |
| シフト | 勤務予定。ご自身で申請し、お店が確定させます |
| シフト申請 | 働きたい日付・時間をお店に申し出ること |
| 募集枠 | お店が公開している空きシフト。応募できます |

## 予約に関する用語
| 用語 | 説明 |
|------|------|
| 予約 | お客様・コース・ルーム・時間を組み合わせた 1 件の受付 |
| コース | 提供するサービスの単位。「お試しコース」と「通常コース」があります |
| オプション | コースに追加できる有料の選択肢 |
| 延長 | 規定時間を超えて延長すること |
| ルーム | 接客を行う部屋 |

## 指名に関する用語
| 用語 | 説明 |
|------|------|
| 本指名 | 以前にご利用いただいたお客様からの名指しのご指名 |
| 写真指名 | 写真を見て、はじめてご指名いただくこと |

指名の呼び方はお店ごとに決められています。上記以外の呼び方を使っているお店もあります。

## その他
| 用語 | 説明 |
|------|------|
| 顧客 | ご来店・ご予約いただくお客様 |
| レポート | ご自身の実績の集計 |
| 報酬 | お店から支払われる金額 |
| マイページ | ご自身のプロフィールや設定を確認・変更する画面 |
| PWA | ブラウザのページをホーム画面に追加して、アプリのように使う仕組み |
