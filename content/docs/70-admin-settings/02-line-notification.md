# LINE通知設定

<Callout type="note" title="必要なプラン・権限">
LINE通知設定は店舗設定の一部です。管理者（owner／admin）でのアクセスを前提とします。
</Callout>

## できること
- LINE Messaging API 連携の設定手順を確認できる
- Webhook・シークレットキー・アクセストークンを入力して連携を設定できる
- 通知のオン／オフを設定できる

## 事前準備
- 管理画面に管理者（owner／admin）でログインしていること
- LINE Developers でチャネルを作成し、Webhook・シークレットキー・アクセストークンを取得しておくこと

## 手順

### 設定手順を確認する
1. 店舗設定から「LINE通知設定」（/settings/line）を開きます
2. 画面上部の「設定手順」で、LINE Developers での準備から本画面への入力までの流れを確認します

<Figure alt="LINE通知設定の設定手順ガイド" caption="LINE Developers での準備から入力までの手順を確認できます" />

### 連携情報を入力する
1. 右上の「編集する」を押します
2. 「連携設定」でWebhook・シークレットキー・アクセストークンを入力します
3. 通知のオン／オフを設定します
4. 「保存する」を押します

<Figure alt="LINE連携設定の入力欄" caption="Webhook・シークレットキー・アクセストークンを入力して連携します" />

## 確認ポイント
- 保存後に「保存しました」の表示が出ること
- LINE Developers 側のWebhook設定と本画面の内容が一致していること

## よくあるミス
- シークレットキーやアクセストークンを取り違えて入力する（LINE Developers の値をそのまま貼り付けます）
- 秘匿情報のため、シークレットキーやアクセストークンを第三者に共有してしまう（取り扱いに注意します）
