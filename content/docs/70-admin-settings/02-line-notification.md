# LINE通知設定

<Callout type="warning" title="必要なプラン・権限">
**オーナーだけ**が開けます。設定には LINE 側での準備が必要です。
</Callout>

## できること
- お店の LINE公式アカウントと pixi をつなげられる
- つなげると、LINE でお客様にお知らせを送れるようになる

<Callout type="note">
この設定は、**普段の運用では触りません。**お店を立ち上げるときに一度だけ行う作業です。LINE 側の専門的な画面を使うため、迷ったら pixi のサポートにご相談ください。
</Callout>

## 事前準備
- オーナーの立場でログインしていること
- お店の LINE公式アカウントがあること
- LINE Developers（LINEの開発者向けサイト）にログインできること

## 手順

### 設定画面を開く
1. 画面の右上にある、自分の名前が出ている部分を押します
2. 「店舗設定」を選び、その中の「LINE通知設定」を開きます
3. 画面に、上から順に5つの手順が出ています

<Figure src="/manuals/admin/70-admin-settings/02-line-notification/01-line-settings.jpg" alt="LINE通知設定の画面。1から5までの設定手順が並んでいる" caption="画面に設定手順が1から5まで書かれています。上から順に進めます" />

### 5つの手順
画面に書かれているとおりに、上から進めます。

| 手順 | やること | 作業する場所 |
|:--:|------|------|
| 1 | LINE公式アカウント（Messaging API チャネル）を用意する | LINE Developers |
| 2 | Webhook URL を登録する | LINE Developers |
| 3 | Webhook の利用をオンにする | LINE Developers |
| 4 | チャネルシークレットとアクセストークンを控える | LINE Developers |
| 5 | 控えた内容をこの画面に入力して保存する | pixi の管理画面 |

<Callout type="tip">
手順2で貼り付ける「Webhook URL」は、この画面の下のほうにある「連携設定」に表示されています。コピーして LINE 側に貼り付けてください。
</Callout>

### 入力して保存する
1. 画面右上の「編集する」を押します
2. 「Webhook URL」「チャネルシークレット」「アクセストークン」を入力します
3. 必要に応じて「通知」欄にメモを書きます
4. 「保存する」を押します

<Callout type="warning">
**チャネルシークレットとアクセストークンは、LINE のアカウントを操作できてしまう大切な情報です。**メールやチャットで人に送ったり、画面を撮影して共有したりしないでください。
</Callout>

## 確認ポイント
- 保存したあと、テストのお知らせが LINE に届くこと
- LINE Developers 側で「Webhookの利用」がオンになっていること

## よくあるミス
- 「Webhookの利用」をオンにし忘れて、お知らせが届かない
- アクセストークンを短期のものにしてしまう（長期のものを使います）
- コピーするときに前後の空白が入ってしまう（余分な空白は消してください）
