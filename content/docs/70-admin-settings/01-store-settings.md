# 店舗設定

<Callout type="warning" title="必要なプラン・権限">
**オーナーだけ**が開けます。スタッフには「店舗設定」が表示されません。
</Callout>

## できること
- お客様に見せるお店の情報（バナー画像・アイコン・連絡先）を設定できる
- ご契約の内容を確認できる
- Web予約の受け付けかたを設定できる
- pixi の中のスケジュールの見せかたを設定できる
- お客様に送るメッセージの文面を設定できる

## 事前準備
- オーナーの立場でログインしていること

## 手順

### 店舗設定を開く
1. 画面の右上にある、自分の名前が出ている部分を押します
2. 「店舗設定」を選びます

<Figure src="/manuals/admin/70-admin-settings/01-store-settings/01-store-settings.jpg" alt="店舗設定の画面。上に設定の切り替え、下に店舗情報" caption="上のボタンで見たい設定に移動できます" />

### 設定のまとまりを選ぶ
画面の上に、大きく2つの切り替えがあります。

| 切り替え | 内容 |
|------|------|
| すべての設定 | お店の情報・契約・Web予約・スケジュールなど |
| メッセージ設定 | お客様に送る文面 |

「すべての設定」の中は、さらに5つに分かれています。ボタンを押すと、その場所まで移動します。

| ボタン | 内容 |
|------|------|
| 店舗情報 | バナー画像・お店のアイコン・店舗ID・連絡先 |
| 契約情報 | ご契約中のプランなど |
| Web予約フォーム内設定 | Web予約の受け付けかた |
| Pixi内スケジュール設定 | スケジュール画面の見せかた |
| その他店舗設定 | 上記以外の設定 |

### 内容を変える
1. 変えたいまとまりの右上にある「編集する」を押します
2. 内容を入力します
3. 保存します

<Callout type="note">
「店舗ID」は、システムがお店を見分けるための番号です。**変更はできません。**お問い合わせのときにお伝えいただくことがあります。
</Callout>

<Callout type="warning">
バナー画像とお店のアイコンは、**お客様のWeb予約ページに表示されます。**差し替えるときは、公開して問題のない画像かどうか必ず確認してください。
</Callout>

## 確認ポイント
- バナー画像・アイコンが、今のお店の雰囲気に合っているか
- 連絡先が最新のものになっているか
- 変更したあと、実際のWeb予約ページを開いて見え方を確認すること

## よくあるミス
- スタッフの立場でログインしていて、店舗設定が見つからない（オーナーだけの画面です）
- 「編集する」を押さずに入力しようとする（先に編集の状態にします）
- 保存を押さずに別の画面へ移動してしまう
