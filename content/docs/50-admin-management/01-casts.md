# キャスト管理

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご利用いただけます。
</Callout>

## できること
- 在籍しているキャストを一覧で確認できる
- 退店したキャストを分けて確認できる
- 名前で探せる
- 本指名の本数と売上をキャストごとに確認できる
- 新しいキャストを登録できる

## 事前準備
- 管理画面にログインしていること

## 手順

### キャスト一覧を開く
1. 画面左のメニューから「キャスト」を押します
2. キャストがカードで並びます。画面の上に「24名のキャスト」のように人数が出ます

<Figure src="/manuals/admin/50-admin-management/01-casts/01-cast-list.jpg" alt="キャスト一覧。カードに写真・名前・SNS・本指名本数・売上" caption="キャスト1人ずつがカードで並びます。右上の色で掲載の状態が分かります" />

カードには次の内容が出ます。

| 表示 | 意味 |
|------|------|
| 写真・名前 | 登録されている写真とお名前 |
| X・Instagram などのマーク | そのキャストのSNS |
| 年齢・身長・スリーサイズ | プロフィール |
| 本指名 ◯本 | 本指名で入ったご予約の本数 |
| 売上 ￥◯ | そのキャストの売上 |
| 掲載中（緑） | Web予約のページに出ている |
| 未掲載（オレンジ） | Web予約のページに出ていない |

### 在籍と退店済みを切り替える
画面の左上に2つのボタンがあります。

1. 「在籍」を押すと、今いるキャストが出ます
2. 「退店済み」を押すと、辞めたキャストが出ます

<Callout type="note">
退店したキャストも記録として残ります。過去の予約や売上を確認するために必要なので、削除はしません。
</Callout>

### キャストを探す
右上の検索欄に名前を入れると、その場でしぼり込まれます。

### 詳しい内容を見る・直す
カードを押すと、そのキャストの詳しい画面が開きます。プロフィール・写真・報酬の設定などを確認・変更できます。

### 新しいキャストを登録する
1. 画面右上の「＋ 新規登録」を押します
2. 名前・プロフィール・写真などを入力します
3. 登録します

<Callout type="tip">
登録しただけでは、Web予約のページには出ません。お客様に見せる場合は「掲載中」にする必要があります。
</Callout>

## 確認ポイント
- 新しく登録したキャストが「掲載中」になっているか
- 辞めたキャストが「在籍」に残っていないか

## よくあるミス
- 「退店済み」を表示したままで、在籍キャストが出てこないと勘違いする
- 登録しただけで「未掲載」のままになっていて、Web予約に出ない
