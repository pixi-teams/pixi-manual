# 顧客管理

<Callout type="note" title="必要なプラン・権限">
どのご契約でも、どの担当者でもご利用いただけます。
</Callout>

## できること
- お客様の人数・当月の来店数・累計の売上をひと目で確認できる
- お名前・電話番号・顧客ID・メールアドレスで探せる
- お客様の状態（良好・要注意・出禁）でしぼり込める
- 利用日や利用回数でしぼり込める

## 事前準備
- 管理画面にログインしていること

## 手順

### 顧客一覧を開く
1. 画面左のメニューから「顧客」を押します
2. いちばん上に3つのまとまりが出ます

| まとまり | 意味 |
|------|------|
| 総顧客数 | 登録されているお客様の人数 |
| 当月の来店 | 今月ご来店いただいた人数 |
| 累計売上合計 | これまでの売上の合計 |

<Figure src="/manuals/admin/50-admin-management/02-customers/01-customer-list.jpg" alt="顧客一覧。上に3つの集計、下に検索と絞り込み、その下に顧客の行" caption="上の3つで全体を、下の一覧で1人ずつを確認します" />

### お客様を探す
検索欄に、お名前・電話番号・顧客ID・メールアドレスのいずれかを入れます。

### しぼり込む
検索欄の下に「絞り込み」があります。

**お客様の状態**

| ボタン | 意味 |
|------|------|
| 良好 | 問題なくご利用いただいているお客様 |
| 要注意 | 対応に気をつけたいお客様 |
| 出禁 | ご利用をお断りしているお客様 |

**利用日** — 指定なし／今日／今週／今月／カレンダーで指定 から選べます

**利用回数** — 指定なし／1回以上／3回以上／5回以上／10回以上 から選べます

<Callout type="tip">
「利用回数 10回以上」でしぼり込むと、常連のお客様だけを表示できます。
</Callout>

### 一覧の見かた
1人ずつの行には、登録日・顧客ID・名前・利用回数・最終利用日・電話番号・メールアドレス・状態が出ます。

右端の「↗」を押すと、そのお客様の詳しい画面が開きます。

<Callout type="warning">
「要注意」「出禁」の表示は、お客様の目に触れない場所で扱ってください。画面をお客様に見せながらの操作は避けてください。
</Callout>

## 確認ポイント
- 予約を受ける前に、そのお客様の状態（良好・要注意・出禁）を確認すること
- しぼり込みを解除するときは「指定なし」に戻すこと

## よくあるミス
- しぼり込んだままになっていて、探しているお客様が出てこない
- 同じお客様が電話番号違いで二重に登録されている（登録前に電話番号で検索します）
