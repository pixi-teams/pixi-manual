# 顧客管理

<Callout type="note" title="必要なプラン・権限">
すべてのプランで利用できます。顧客はWeb予約や予約作成を通じて登録されるため、この画面から新規作成はできません。
</Callout>

## できること
- 総顧客数・当月の来店・累計売上合計を統計カードで確認できる
- 名前・電話番号・ふりがな・顧客ID・メールで検索できる
- 良好／要注意／出禁のステータスで絞り込める
- 顧客の基本情報やメモをその場で編集できる
- 出禁（自店・他店共有）の状態をバナーで確認できる
- 来店履歴を確認できる

## 事前準備
- 管理画面にログインしていること

## 手順

### 顧客を探す
1. サイドメニューの「顧客」を開きます
2. 画面上部で総顧客数・当月の来店・累計売上合計を確認します
3. 検索ボックスに名前・電話・ID・メールを入力します
4. 「絞り込み」の「良好」「要注意」「出禁」などで条件を追加します

<Figure alt="顧客一覧の統計カードと検索・絞り込み" caption="統計カードと検索・ステータス絞り込みで顧客を探せます" />

### 詳細を編集する
1. 顧客カードを押して詳細画面を開きます
2. 「基本情報」の「編集する」を押します
3. 名前・ふりがな・電話番号・メール・ステータス・キャストNG・指名キャストなどを編集します
4. 「店舗用メモ」「キャスト用メモ」に共有事項を記入します
5. 「保存する」を押します

<Figure alt="顧客詳細の基本情報のインライン編集" caption="基本情報やメモをその場で編集できます" />

### 出禁の状態を確認する
1. 詳細画面の上部に表示されるバナーを確認します
2. 自店で出禁の場合は赤いバナー、他店で共有された出禁の場合はオレンジ（amber）のバナーが表示されます

<Figure alt="出禁顧客に表示される警告バナー" caption="自店出禁は赤、他店共有出禁はオレンジで表示されます" />

## 確認ポイント
- 編集した内容が詳細画面に反映されていること
- 出禁バナーが表示された顧客は、店舗の対応方針を管理者に確認していること

## よくあるミス
- この画面から顧客を新規追加しようとする（予約経由で登録されます）
- 他店共有出禁のバナーを見落とす（オレンジのバナーも出禁扱いです）
