# スタッフ管理

<Callout type="note" title="必要なプラン・権限">
pro／ultra のご契約でご利用いただけます。basic では「スタッフ」のメニューが表示されません。
</Callout>

## できること
- お店のスタッフを一覧で確認できる
- 今ログインしている人が分かる
- ログインしたままのスタッフを、強制的にログアウトさせられる
- 新しいスタッフを登録できる
- スタッフごとに、見せるメニューを決められる

## 事前準備
- 管理画面にログインしていること
- pro／ultra のご契約であること

## 手順

### スタッフ一覧を開く
1. 画面左のメニューから「スタッフ」を押します
2. 画面の上に「11名のスタッフ・5名ログイン中」のように人数が出ます

<Figure src="/manuals/admin/50-admin-management/03-staffs/01-staff-list.jpg" alt="スタッフ一覧の表。スタッフ名・ログインID・状態・最終ログイン・操作" caption="今ログインしている人には緑の「ログイン中」が付きます" />

表には次の内容が出ます。

| 列 | 内容 |
|------|------|
| スタッフ名 | お名前 |
| ログインID | ログインに使うID |
| ステータス | ログイン中（緑）／未ログイン（灰色） |
| 最終ログイン | 最後にログインした日時。一度もない場合は「ログイン履歴なし」 |
| アクション | 強制的にログアウトさせるボタン |

### スタッフを探す
検索欄に、スタッフ名またはログインIDを入れます。

### 強制的にログアウトさせる
共用のパソコンでログインしたままになっているときなどに使います。

1. 対象のスタッフの行の右端にある赤い「ログアウト」を押します
2. そのスタッフは、次の操作からログインし直しになります

<Callout type="warning">
この操作は**オーナーだけ**が行えます。作業中のスタッフを強制ログアウトすると、入力中の内容が失われる場合があります。声をかけてから行ってください。
</Callout>

<Callout type="note">
「未ログイン」のスタッフには、ログアウトのボタンが灰色になっていて押せません。すでにログアウトしているためです。
</Callout>

### 新しいスタッフを登録する
1. 画面右上の「＋ 新規登録」を押します
2. お名前・ログインID・パスワード・立場（オーナー／スタッフ）を入力します
3. 見せるメニュー（レポート・経費・請求）を決めます
4. 登録します

### 見せるメニューを変える
1. 一覧からスタッフを押して、詳しい画面を開きます
2. 「レポート」「経費」「請求」の表示・非表示を切り替えます

<Callout type="tip">
「あるはずのメニューが出ない」と相談されたときは、まずここを確認してください。
</Callout>

## 確認ポイント
- 退職したスタッフのアカウントが残っていないか
- 立場（オーナー／スタッフ）が、その人の役割に合っているか

## よくあるミス
- 退職者のアカウントを消し忘れる
- 経理を担当しないスタッフに、経費や請求を見せる設定のままにしてしまう
- basic のご契約でスタッフのメニューを探してしまう（pro／ultra だけの機能です）
