# スタッフ管理

<Callout type="note" title="必要なプラン・権限">
スタッフ管理はProプラン・Ultraプランで利用できます。強制ログアウトの操作は管理者（owner／admin）のみ行えます。従来「ユーザー管理」と呼んでいた機能に相当します。
</Callout>

## できること
- 登録済みスタッフを一覧で確認し、ログイン中の人数を把握できる
- スタッフ名またはログインIDで検索できる
- 新規スタッフを登録できる
- 詳細画面で基本情報・表示設定・権限を編集できる
- メニューの表示（経費・レポート・請求）をスタッフごとに切り替えられる
- ログイン中のスタッフを強制ログアウトできる（管理者のみ）

## 事前準備
- 管理画面にログインしていること
- 表示設定や権限を変更する場合は管理者（owner／admin）でログインしていること

## 手順

### スタッフを探す
1. サイドメニューの「スタッフ」を開きます
2. 見出し下で在籍人数とログイン中の人数を確認します
3. 検索ボックスにスタッフ名またはログインIDを入力します

<Figure alt="スタッフ一覧とログイン中人数の表示" caption="ログイン中の人数を確認し、名前やログインIDで検索できます" />

### 新規登録する
1. 一覧右上の「新規登録」を押します（/staffs/new に進みます）
2. 「基本情報」で名前・メールアドレス・ログインID・パスワードを入力します
3. 「表示設定」で「経費」「レポート」「請求」の各メニューを表示するか切り替えます
4. 「権限」で「オーナー」または「スタッフ」を選びます
5. 内容を確認して登録します

<Figure alt="スタッフ新規登録の基本情報と権限設定" caption="基本情報・表示設定・権限を設定して登録します" />

### メニュー表示や権限を変更する
1. 一覧からスタッフの行を押して詳細画面を開きます
2. 「表示設定」の「編集する」で経費・レポート・請求の表示／非表示を切り替えます
3. 「権限」の「編集する」で管理者（オーナー）／一般（スタッフ）を切り替えます
4. 「保存する」を押します

<Figure alt="スタッフ詳細の表示設定トグルと権限カード" caption="メニュー表示のトグルと権限をセクションごとに編集します" />

### 強制ログアウトする
1. 管理者（owner／admin）でログインしていると、一覧に「アクション」列が表示されます
2. ログイン中のスタッフの行でログアウト操作を実行します

<Figure alt="ログイン中スタッフの強制ログアウト操作" caption="管理者はログイン中のスタッフを強制ログアウトできます" />

## 確認ポイント
- 表示設定を変えたスタッフのメニューに、経費・レポート・請求が意図どおり表示／非表示になっていること
- 権限が意図したとおり（管理者／一般）になっていること

## よくあるミス
- 一般（スタッフ）権限のまま、経費・レポート・請求のメニューが見えないと問い合わせる（表示設定のトグルを確認します）
- 一般スタッフを管理者へ昇格しようとする（原則、管理者権限を持つスタッフのみ昇格できます）
